# Boilerplate

[liberusoftware/boilerplate-laravel](https://github.com/liberusoftware/boilerplate-laravel) is the shared SaaS starting point — Laravel 13, PHP 8.5, Filament 5 and Livewire 4, with Jetstream and Socialite wired in — that every Liberu application (CRM, ERP, ecommerce, CMS, billing, real estate) is built from.

Starting a new Liberu-based application means forking or composing on top of the boilerplate, then installing the [modules](./module-architecture.md) that specific application needs — messaging, accounting, and so on.
