# CMS

[liberusoftware/cms-laravel](https://github.com/liberusoftware/cms-laravel) is a content management system built on Laravel 13, PHP 8.5 and Filament 5 — an alternative to WordPress, Drupal or OctoberCMS for teams already standardised on the Liberu / Laravel stack.
