# Real Estate

[liberusoftware/real-estate-laravel](https://github.com/liberusoftware/real-estate-laravel) is a property agency platform built on Laravel 13, PHP 8.5 and Filament 5, with support for Rightmove, Zoopla and OnTheMarket listing feeds.
