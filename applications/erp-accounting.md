# ERP & Accounting

[liberusoftware/accounting-erp-laravel](https://github.com/liberusoftware/accounting-erp-laravel) is a self-hosted accounting application — positioned against QuickBooks, Xero, FreeAgent and Akhaunting ERP — built on Laravel 13, PHP 8.5 and Filament 5.

Like every Liberu application, it's assembled from versioned Composer modules rather than shipped as one fixed codebase; see [Module architecture](../platform/module-architecture.md) for how a host app declares and installs the modules it runs.
