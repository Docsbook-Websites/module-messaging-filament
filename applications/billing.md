# Billing

[liberusoftware/billing-laravel](https://github.com/liberusoftware/billing-laravel) is a web hosting billing system — supporting cPanel, Plesk, DirectAdmin and VirtualMin — built on Laravel 12, PHP 8.5, Filament 5 and Livewire 4. Positioned as an alternative to WHMCS, Blesta or HostBill.
